# 海外及港台直播每日检测

固定订阅文件：`live.m3u`。UHF使用该文件的Raw地址，不是GitHub网页地址。

## 日常更新

工作流计划每天北京时间08:17运行，也可在Actions手动执行。GitHub定时任务可能延迟或停用，检查`report.json`的时间确认最近运行。首个工作流运行成功之前，不代表计划已经可用。

检测不是ping：读取HLS清单、下载最后3个视频分片，并用离线ffprobe检查一个样本的视频轨道，并用离线 ffmpeg 实际解码一帧。仅证明该短样本可解码，不代表持续流畅、声音正常或 Apple TV 播放兼容。报告下载时间/视频时长比例，超过1表示样本下载不及播放速度。云端结果不代表中国大陆家庭网络、代理节点或Apple TV实际播放，也不验证频道实时节目与原生画质。

保持原始`sources.m3u`。同一频道若提供多条候选，选择本轮通过且下载比例较低的一条；单次失败保留原链接，连续3次失败才从海外输出 `overseas.m3u` 隔离。后续恢复则重新加入。整体通过率低于30%时仅更新报告，避免云端网络故障清空订阅。

当前候选集合来自人工整理的49个海外及港台频道。国内电视以家庭电信 IPTV 为主，按所有者授权将杭州清单独立保存在 domestic.m3u，不参与海外检测。本工作流检查、重排已配置候选，不会凭空发现新的替代地址；失效地址需审查后补充至`sources.m3u`。不要把“每日刷新”理解为自动保证所有台永不失效。

## 安全与使用范围

### 无法检测不等于失效

加密 HLS、字节范围分片等检测器尚不支持的格式，以及云端返回 HTTP 401/403/451 的访问限制，标为 `untestable`，不算检测通过，也不累计为连续失败。没有可通过候选时保留该候选并明确标注未验证；不会请求密钥、绕过访问限制或把它写为最近通过源。未知结果会打断连续失败计数，避免仅因云端检测能力或地域限制误删频道。确认不安全的目标仍然排除。

HTTP/HTTPS每次请求（包括跳转、嵌套清单和视频片段）解析所有DNS结果并拒绝非公网地址，连接锁定验证过的IP，HTTPS仍验证证书。禁用环境代理；不请求密钥、内网、登录或付费解锁。ffprobe 和 ffmpeg 只能读管道中的字节，不允许网络协议；帧解码仅接受 MPEG-TS/MP4 容器，15 秒超时，最多输出一帧缩为 1×1 的 RGB 数据。样本无法解码（包括缺少关键帧、缺少解码器或超时）标为 `untestable`，不冒充通过或确认失效。每频道独立进程施加90秒强制期限，另设置请求超时、大小限制、4路并发和工作流时长上限。拒绝私网、保留、组播及IPv6转换地址。

这些是公开聚合直播链接，不全是电视台官方源。运营方及转播授权未逐条确认。请遵守当地法律及服务条款。源码和地址公开前应由仓库所有者确认；不要加入任何订阅凭据或个人 token。家庭地址仅按所有者明确授权公开。

GitHub Actions使用默认仓库token写回本仓库，不需要添加个人访问令牌。工作流只应部署在专用仓库，不接受外部PR触发。

## 本地检查

需要Python 3.10+、ffprobe 及 ffmpeg。`python3 -m unittest discover -s tests -v`，再执行`python3 scripts/check.py`。该脚本会在所在目录写入检测报告与清单。

## 国内 IPTV 与海外合并

固定订阅仍为 `live.m3u`。`domestic.m3u` 是用户同意公开的家庭 IPTV 清单，包含局域网服务地址，仅在相应家庭网络内可用。保留原分组、EPG、广播和画质版本，不按重复 tvg-id 合并。

云端检测只读取 `sources.m3u`，更新 `overseas.m3u`。之后 `scripts/merge.py` 只进行文本合并，将国内清单放在前面，不请求国内视频、EPG或图标。即使海外发生广泛故障，国内条目也不会被检测器移除。不得向 `sources.m3u` 加入家庭地址。

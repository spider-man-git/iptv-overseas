# 海外及港台直播每日检测

固定订阅文件：`live.m3u`。UHF使用该文件的Raw地址，不是GitHub网页地址。

## 日常更新

工作流计划每天北京时间08:17运行，也可在Actions手动执行。GitHub定时任务可能延迟或停用，检查`report.json`的时间确认最近运行。首个工作流运行成功之前，不代表计划已经可用。

检测不是ping：读取HLS清单、下载最后3个视频分片，并用离线ffprobe检查一个样本的视频轨道。报告下载时间/视频时长比例，超过1表示样本下载不及播放速度。云端结果不代表中国大陆家庭网络、代理节点或Apple TV实际播放，也不验证频道实时节目与原生画质。

保持原始`sources.m3u`。同一频道若提供多条候选，选择本轮通过且下载比例较低的一条；单次失败保留原链接，连续3次失败才从`live.m3u`隔离。后续恢复则重新加入。整体通过率低于30%时仅更新报告，避免云端网络故障清空订阅。

当前候选集合来自人工整理的49个海外及港台频道。国内电视以家庭电信IPTV为主，完全不加入本公开仓库。本工作流检查、重排已配置候选，不会凭空发现新的替代地址；失效地址需审查后补充至`sources.m3u`。不要把“每日刷新”理解为自动保证所有台永不失效。

## 安全与使用范围

HTTP/HTTPS每次请求（包括跳转、嵌套清单和视频片段）解析所有DNS结果并拒绝非公网地址，连接锁定验证过的IP，HTTPS仍验证证书。禁用环境代理；不请求密钥、内网、登录或付费解锁。ffprobe只能读管道中的字节，不允许网络协议。每频道独立进程施加90秒强制期限，另设置请求超时、大小限制、4路并发和工作流时长上限。拒绝私网、保留、组播及IPv6转换地址。

这些是公开聚合直播链接，不全是电视台官方源。运营方及转播授权未逐条确认。请遵守当地法律及服务条款。源码和地址公开前应由仓库所有者确认；不要加入任何订阅凭据、个人token或私人地址。

GitHub Actions使用默认仓库token写回本仓库，不需要添加个人访问令牌。工作流只应部署在专用仓库，不接受外部PR触发。

## 本地检查

需要Python 3.10+及ffprobe。`python3 -m unittest discover -s tests -v`，再执行`python3 scripts/check.py`。该脚本会在所在目录写入检测报告与清单。

## 家庭电信 IPTV 的分离方式

推荐在UHF分别添加两个播放列表：
1. 本仓库的海外/港台固定Raw地址，云端每日检测。
2. 私人本地导入的家庭IPTV清单。若需要HTTP转发，可由家中路由器/常开设备提供仅局域网可达的服务。

家庭IPTV的组播地址、网关、设备地址、订阅凭据、抓包及日志不提交本公开仓库。GitHub云端不能检测家庭组播，也不应访问私人网络。国内源的本地检测需等家庭网络与接收方式确认后另行配置。

如希望合成一个订阅，可在家庭设备本地合并本仓库公开清单和私有IPTV清单，合成文件仍只在家中提供，不上传GitHub。并非必须部署NAS，是否需要转发设备取决于光猫/路由器的IPTV与组播配置以及播放器支持。
